help_outline Possible Causes & Fixes:

  • Server Offline: Ensure your BallisticaKit server is launched and listening on the specified port.
  • Local IP Detection: Local / private LAN addresses (e.g. 127.0.0.1, 172.x.x.x, 192.168.x.x) bypass the proxy and require local network access.
  • Proxy Unresponsive: If you are connecting to a remote public server, the HTTPS proxy might be experiencing downtime.
